# MAITE

**Private AI companion built around a locked diary. Pronounced "Mate."**

[hellomaite.com](https://hellomaite.com)

---

## What it is

MAITE is an AI companion app where the diary stays locked. Users get a private space to think, vent, plan, and reflect, with an AI that listens without judgement and remembers what matters. Voice in, voice out, text when you want it. The architecture is locked-diary by design: your entries never train a model, never leave your account, never become someone else's training data.

Built for the people who tried journaling apps and quit because every entry felt like it was being watched.

## Stack

Built with TypeScript, Node, MLX (local inference), and Stripe. Audio pipeline runs Qwen3-TTS. Vision via local MLX server. The whole thing runs on consumer hardware (Mac M4 Pro), no cloud API costs, no data harvesting. Founder licenses available at [hellomaite.com](https://hellomaite.com).
